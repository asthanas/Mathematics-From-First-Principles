# Arithmetic & Number Sense

**Stage 01**

## Purpose
This stage builds understanding from beginner-friendly intuition toward formal mathematics. Do not treat the list as a checklist to memorize; use it as a map for lessons, examples, exercises and projects.

## Learning Outcomes
- Explain the ideas in plain language.
- Use notation correctly.
- Solve basic and unfamiliar problems.
- Derive or justify important results where appropriate.
- Visualize the ideas when possible.
- Implement selected calculations in Python.
- Connect the ideas to previous and future mathematics.

## Topics and Subtopics
- [ ] Natural/whole/integer numbers
- [ ] Rational and irrational numbers
- [ ] Real number line
- [ ] Arithmetic operations
- [ ] Order of operations
- [ ] Factors, multiples and primes
- [ ] GCD and LCM
- [ ] Powers and roots
- [ ] Scientific notation
- [ ] Estimation and significant figures

## Beginner Questions
For every subtopic, answer:
1. What is it?
2. Why was it introduced?
3. What problem does it solve?
4. What do the symbols mean?
5. Can I make a simple example?
6. What is a common mistake?
7. Where is it used?

## Mastery Gate
- [ ] Definitions understood
- [ ] Notation understood
- [ ] Beginner exercises completed
- [ ] Intermediate exercises completed
- [ ] At least two unfamiliar problems solved
- [ ] Key formulas/results explained or derived
- [ ] One visualization or computational experiment completed
- [ ] One real-world/application example understood
