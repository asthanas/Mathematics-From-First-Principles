# Mathematics Journey

> **From first principles to advanced mathematics for AI/ML, engineering, quantum computing and research.**

A long-term mathematics knowledge repository built for beginners but designed to grow into university-level, advanced, applied and research mathematics.

## Learning Loop

**Understand → Visualize → Derive → Practice → Implement → Apply → Explain → Review**

## Curriculum
31 stages from mathematical thinking through arithmetic, algebra, geometry, trigonometry, calculus, linear algebra, probability, statistics, discrete mathematics, differential equations, numerical methods, optimization, analysis, algebra, information theory, AI/ML mathematics, modeling, quantum mathematics, QML, research and mathematical maturity.

## Beginner Rule
If a later topic feels difficult, return to its prerequisites. Going backward is part of learning mathematics.

## Mastery
A topic is complete only when you can explain it, calculate with it, reason about it, and apply it—not merely recognize a formula.
